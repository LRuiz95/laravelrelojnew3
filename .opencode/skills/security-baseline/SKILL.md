# Security Baseline

Check secrets, environment configuration, authentication, authorization, CSRF/XSS/SQL injection where applicable, file upload/download, SSRF, unsafe deserialization, error exposure, logs, dependency risk and access control.

Give evidence and severity, not generic warnings.
