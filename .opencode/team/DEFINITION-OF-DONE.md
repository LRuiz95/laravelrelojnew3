# DEFINITION OF DONE

- [ ] Objective is satisfied.
- [ ] Pre-change Git checkpoint/rollback point was established.
- [ ] Existing consumers/references of changed code/contracts were searched before editing.
- [ ] No signature/contract/schema change was left with an unverified consumer.
- [ ] Real project versions/conventions were preserved.
- [ ] Dependencies/consumers were checked.
- [ ] Relevant tests were executed.
- [ ] Security was checked when applicable.
- [ ] Final diff was independently reviewed.
- [ ] No accidental files or secrets remain.
- [ ] Remaining risks are documented.
- [ ] Human has clear continuation options and a recommended next step.
- [ ] Git state is clean or intentionally documented.
