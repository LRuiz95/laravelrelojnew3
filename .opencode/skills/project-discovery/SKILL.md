# Project Discovery

Use before unfamiliar work.

1. Locate project rules and agent instructions.
2. Detect language/framework/runtime versions from real files.
3. Find entry points and dependency edges.
4. Identify tests/build/lint commands.
5. Identify sensitive files and operational constraints.
6. Separate observed facts from assumptions.

Never infer a framework or version from naming alone.
